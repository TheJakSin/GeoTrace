# GeoTrace

Программа для оцифровки геопривязанных карт. Создаёт полигоны по цветовым областям скана и позволяет исправить результат вручную, добавить разломы, заполнить атрибуты и подготовить карту к печати.

## Скачать

[Приложения и установщики для Windows и macOS](https://github.com/TheJakSin/GeoTrace/releases/latest)

- **Windows 10/11 x64:** установщик `*-Windows-x64-Setup.exe` или ZIP. По умолчанию программа устанавливается в Program Files.
- **Mac с Apple Silicon:** пакет `*-macOS-arm64.pkg` или ZIP с приложением.
- **Mac с Intel:** пакет `*-macOS-x86_64.pkg` или ZIP с приложением.

Для Mac нужна macOS 14.4 или новее. Python устанавливать отдельно не требуется. Пакеты выпускаются без сертификата издателя; при установке система может запросить подтверждение. Контрольные суммы находятся в файле `SHA256SUMS.txt` рядом с загрузками.

## Работа с картой

1. Добавьте геопривязанные TIFF и контур участка KML. В одном проекте можно использовать несколько листов.
2. Подготовьте цвета каждого листа и запустите оцифровку. При необходимости разделите близкие оттенки пипеткой.
3. Сопоставьте группы соседних листов и проверьте полученные полигоны.
4. Исправьте границы, добавьте линии разломов и заполните атрибуты.
5. Сохраните проект, выгрузите слои в GeoPackage или подготовьте PDF, PNG либо SVG в макете.

В инструменте **Граница** доступны обычное перетаскивание, соединение с соседними полигонами и выбор участка двумя кликами. При соединении можно сохранить контур соседа или провести новую общую линию. Группы и атрибуты объектов сохраняются; правку можно отменить.

Границы сглаживаются при оцифровке. Дополнительный инструмент позволяет выбрать режим, силу и область сглаживания, сравнить результат и применить его. Цвет, толщина и подписи группы меняются нажатием на её образец в слоях.

Карта отображается в EPSG:3857. Площади и длины рассчитываются геодезически на WGS84. Исходные TIFF не изменяются. Автоматический результат нужно проверить по карте; названия геологических подразделений задаёт специалист.

## Для разработки

Нужен Python 3.11. [Подготовка окружения и сборка](docs/RELEASES.md). Проверки: `python tools/check_suite.py`.

Исходные TIFF и рабочие проекты в репозиторий не включаются. Иллюстрации в документации показывают интерфейс на примере проекта двух листов.
