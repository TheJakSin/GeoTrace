# GeoTrace · 0.2.0 alpha 1

Исследовательский прототип настольной оцифровки геологических карт. Приоритет — Windows,
macOS также входит в план. Эта версия разработана и проверена на Mac; испытание на Windows впереди.

## Новое в 0.2

- Локальное выделение по положительным и отрицательным точкам.
- Два метода: «Цвет + подсказки» и необязательный MobileSAM на CPU.
- Видимая рамка анализа 256 / 512 / 768 рабочих пикселей.
- Предварительный просмотр; результат изменяет карту только после «Принять область».
- Принятие области с согласованными границами соседей. Атрибуты оставшихся частей сохраняются.
- Защита ранее принятых и вручную отредактированных объектов от пересечения новой областью.
- Отмена последних 12 действий: принятия областей и применённых изменений атрибутов.
- Происхождение результата (`origin`) сохраняется в GeoPackage.

Сохранились автоматическое выделение цветовых групп по всей карте, просмотр слоёв,
масштабирование, выбор полигона, базовые атрибуты и экспорт с исходной системой координат.

## Как попробовать

1. Откройте привязанный RGB/RGBA GeoTIFF, 8 бит на канал.
2. Перейдите на вкладку **Подсказки**. Выберите размер рамки до первой точки.
3. В режиме **Включить (+)** щёлкните внутри нужной геологической области.
4. В режиме **Исключить (−)** отметьте соседнюю область, которую брать не нужно.
5. Нажмите **Уточнить область**. Оранжевое выделение пока является только предложением.
6. При ошибке добавьте точки, смените метод или допуск цвета и повторите уточнение.
7. Нажмите **Принять область**. Затем переключитесь на **Выбрать полигон**, заполните
   атрибуты и нажмите **Применить атрибуты**.
8. Сохраните результат кнопкой **Экспорт .gpkg**.

Если выделение достигает рамки, программа предупреждает о возможном обрезании объекта.
Можно принять фрагмент явно либо сбросить точки и увеличить рамку. Принятые области защищены:
для их изменения в этой версии нужно сначала отменить принятие, если действие ещё в истории.
`accepted` означает принятие геометрии пользователем, а не автоматическое подтверждение геологии.

Колесо меняет масштаб; перетаскивание перемещает карту; «Вписать» возвращает общий вид.
На вкладке **Авто** запускается первый экспериментальный алгоритм по всей карте.
Повторный полный запуск заменяет результат после подтверждения; локальные подсказки предназначены
для работы с отдельными участками.

## Что пока не решено

**Оба метода ошибаются.** Они не читают геологическую легенду и не определяют подразделение.
На светлых заливках, штриховке, узких полосах и подписях результат может быть неудовлетворительным.
Сравнение на четырёх фрагментах описано в `EVALUATION.md`; это не заявленная точность продукта.

Обработка ограничена изображением до 1600 пикселей по длинной стороне. Охват и привязка сохраняются,
но более мелкие детали теряются. Рамки и пороги измеряются в рабочих пикселях.
Алгоритм подавления печати может ошибочно удалить настоящие тонкие тёмные объекты.

Ещё отсутствуют: рисование границ вручную, полноценные объединение/разделение объектов,
конструктор атрибутов, повторное открытие GeoPackage в приложении, сохранение проекта и
автосохранение, KML-обрезка, отмена выполняющегося вычисления, самостоятельные установщики.
Поля атрибутов попадают в результат только после кнопки «Применить атрибуты».

Экспорт создаёт новый файл, не заменяя существующий. Исходные карты не изменяются.
Произвольные наложения в одном полигональном слое не допускаются. Независимое сглаживание
полигонов отключено для сохранения общих границ. Площадь в физических единицах ещё не вычисляется.

## Установка из исходников

Нужен Python 3.11 и интернет для первого скачивания библиотек.

- macOS: `Start GeoTrace.command`.
- Windows: `Start GeoTrace.bat`.

Это сценарии запуска из исходников, а не установщики. При сбое начальной установки удалите
только созданную рядом папку `.venv` и повторите запуск.

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -e ".[dev]"
.venv/bin/python -m geotrace.app
```

В Windows вместо `.venv/bin/python` используйте `.venv\Scripts\python.exe`.

### Необязательный MobileSAM

Обычная установка не включает PyTorch и модель. На текущем Mac исследовательское окружение
уже настроено; общий сценарий `Открыть GeoTrace.command` рядом с папкой проекта подключает его.
На другой машине установите исследовательские зависимости и официальный MobileSAM:

```sh
python -m pip install -e ".[research]"
python -m pip install "git+https://github.com/ChaoningZhang/MobileSAM.git@f706ad9c4eb7f219c00d9050e46328518ffb65d2"
python -m geotrace.app --sam-checkpoint /absolute/path/to/mobile_sam.pt
```

Для команды установки из Git нужен Git. Веса `weights/mobile_sam.pt` берутся из
[официального репозитория MobileSAM](https://github.com/ChaoningZhang/MobileSAM).
Приложение не скачивает их автоматически и не передаёт карты на сервер.
Исследовательские зависимости и веса не входят в основной дистрибутив GeoTrace.
В этом прототипе нейросеть работает на CPU; GPU/CUDA-ускорение пока не реализовано.

## Разработка и проверки

```sh
python -m pytest -q
python -m build
```

Подготовлен `.github/workflows/checks.yml`: проверки на Windows/macOS и сборка Python-пакета.
Приватный репозиторий: https://github.com/TheJakSin/GeoTrace. Результаты запусков смотрите
во вкладке Actions; наличие workflow само по себе не означает успешную проверку. Wheel не является самостоятельным
установщиком приложения. Карты, веса моделей и результаты обработки исключены из Git.

Подробности: `DEVELOPMENT.md`, `VALIDATION.md`, `EVALUATION.md`.
