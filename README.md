# GeoTrace · 0.3.0 alpha 1

Исследовательский прототип настольной оцифровки геологических карт. Приоритет — Windows,
macOS также поддерживается. Опубликованная 0.2 прошла CI на Windows/macOS; живое испытание на Windows-ПК впереди.

## Рабочее пространство

GeoTrace использует светлую графитовую палитру с синим акцентом. Карта — основное рабочее поле; постоянных боковых панелей правки нет. Первым слева расположен **Просмотр**: карта перемещается и масштабируется без выбора и правки объектов. Он включён при открытии карты. Далее расположены инструменты со значками и подсказками: **Выбрать полигоны**, **Лассо**, **Изменить границу**, **Разделить полигон**, **Создать полигон**, **Изменить вершины**. Меню **⋯** открывает **Перерисовать общую границу**, локальное уточнение области и дополнительные параметры оцифровки. Отдельные вкладки «Авто / Подсказки / Правка» и кнопка «Панель» убраны.

При выделении появляются действия **Объединить · N**, предпросмотр объединения, атрибуты и снятие выбора. Действия построения линии, изменения одной вершины и применения предпросмотра появляются только для соответствующего инструмента. **Слои** открываются значком стопки под инструментами и закрываются крестиком. Видимость и процент непрозрачности исходника/полигонов показаны вместе; ниже находятся подложка, KML и цветовые группы. Нажатие на строку цветовой группы открывает её атрибуты.

Выделение, снятие выбора и открытие панелей сохраняют масштаб и положение карты. Слои, атрибуты, проверка и действия показываются поверх карты. **Вписать** меняет масштаб только по команде пользователя; при первом открытии карта вписывается автоматически. Название проекта выделено и расположено по центру верхней строки.

**F1** или кнопка **?** открывает краткую справку. Наведение на кнопку примерно на полсекунды показывает короткое описание и клавишу, если она назначена. Клавиши инструментов работают и в русской раскладке, отключаются при вводе текста, выборе значений и открытых диалогах.

| Клавиши | Действие |
| --- | --- |
| Q / V / L | Просмотр / выбор / лассо |
| B / C / P / N | Правка границы / разделение / новый полигон / вершины |
| D / K / R | Оцифровка / палитра / проверка |
| G / A / T | Слои / атрибуты / таблица |
| [ / ] | Назад / вперёд по участкам проверки |
| F / + / − | Вписать / увеличить / уменьшить |
| Enter | Предпросмотр линии, применение готовой правки или объединение выбранных |
| Esc / Backspace | Сброс линии или выбор и возврат к просмотру / убрать последнюю точку |
| Ctrl/Cmd+Enter | Применить поля в открытых атрибутах |

В Яндекс Картах используется компактная верхняя строка и скрываемая панель слоёв поверх карты: исходник, полигоны, непрозрачность и контур KML. **G** открывает слои, **F** показывает область проекта, **F5** перезагружает страницу. Переключение вкладок и изменение состояния редактора не перезагружают браузер.

**Атрибуты** открываются только по запросу, компактной панелью поверх края карты. Область заполнения: **Выделенные объекты**, **Группа** или **По фильтру**. Фильтр сочетает группу, поиск, состояние проверки и отсутствие обязательных значений. В таблице также есть отдельный точный фильтр группы. Для нескольких объектов доступно **Только незаполненные**. Значения `0` и `Нет` считаются заполненными. При разных значениях выводится **Разные значения**; изменятся только отредактированные поля. Кнопка **Применить к N объектам** выполняет все изменения одним отменяемым действием. Номер, группа и служебные поля не перезаписываются. Структура полей открывается через **Поля…**.

Короткое одиночное нажатие **Shift** переключает **Исходник / Результат**. Кнопка над картой показывает текущее состояние и делает то же самое. Shift в выделении, перетаскивании, сочетаниях клавиш и вводе текста сравнение не включает. В исходном виде карта доступна для просмотра, перемещения и масштаба; геометрия не редактируется. Переключение не меняет настройки слоёв и данные проекта.

**Проверка · N** открывает навигацию по спорным местам: стрелки, номер участка, причина, отключаемая подсветка и действия **Исправить / Подтвердить участок**. Крестик полностью скрывает проверку и отметки, сохраняя позицию и решения; повторное открытие возвращает тот же участок. Проверка сама не включается после расчёта.

Подготовка цветов занимает рабочее пространство и сохраняет масштаб при повторном открытии того же растра. Повторное нажатие цвета выключает его подсветку; **Подсветка цвета** также отключает/возвращает показ. Отметка участия цвета в оцифровке независима от подсветки. **К карте** возвращает в редактор.

В верхней строке находятся открытие, сохранение, отмена и повтор. **Ctrl/Cmd+Z** отменяет, системное сочетание повтора возвращает отменённое действие. Новая правка создаёт новую ветку истории. **Проект** содержит сохранение под другим именем, экспорт GeoPackage, структуру атрибутов и **Настройки карт** с ключами обоих API. История ограничена 12 действиями и начинается заново после открытия проекта.

## Подложки

Для Яндекса добавлен автоматический дисковый кэш тайлов: до 128 МБ и до 7 дней с учётом более коротких сроков, указанных сервером. Истёкшие и повреждённые записи загружаются повторно. Готовые виды карты сохраняются в пределах сеанса отдельно — до 8 видов и 32 МБ. Выключение и включение слоя, а также возврат к недавно просмотренной области используют кэш. Ключи разделяют области кэша; открытый ключ в именах файлов не сохраняется. **Обновить** явно запрашивает свежие тайлы Яндекса.

В разделе **Слои** включите **Подложка**. Источник **Спутник EOX · 2016** подключается без API-ключа. Это архивная мозаика Sentinel-2, доступная по CC BY 4.0 с указанием источника. Условия EOX приведены на https://cloudless.eox.at/documentation/faq. Подпись источника отображается под картой.

Источник **Яндекс · схема** использует официальный Tiles API. В приложение встроен стандартный ключ. Для использования своего ключа откройте **Проект → Настройки карт → Изменить ключ Tiles API…**. Кнопка **Стандартный** возвращает ключ приложения. Свой ключ получают для пакета Tiles API на https://developer.tech.yandex.ru/. Активация нового ключа может занять до 15 минут. Свой ключ хранится в настройках этого компьютера. Файл проекта содержит выбор источника и его видимость.

Для тайлов явно задана проекция Web Mercator, совместимая с перепроецированием подложки в координаты карты. Логотип Яндекса и ссылка на условия отображаются поверх схемы. Логотип открывает Яндекс Карты. Ошибка доступа к ключу и превышение лимита запросов показываются в панели слоя. Кнопка **Обновить** повторяет загрузку. Формат запросов описан на https://yandex.ru/maps-api/docs/tiles-api/request.html.

Снятие флажка **Подложка** отключает выбранный источник. Список переключает один активный слой между EOX, Яндексом и своим GeoTIFF. Выбор и выключение сохраняются в проекте.

При первом включении полностью непрозрачная карта становится полупрозрачной. Ползунок **Непрозрачность карты** позволяет сравнивать её со снимком. Можно снять **Исходная карта**, чтобы рассмотреть подложку отдельно. При перемещении и увеличении загружается видимая часть снимка. Загрузка выполняется в фоне, тайлы повторно используются из локального кэша. Кнопка **Обновить** повторяет расчёт текущего вида после ошибки загрузки.

Для своего снимка выберите **Свой GeoTIFF → Выбрать снимок…**. Поддерживаются цветные геопривязанные снимки, включая 16-битные RGB-каналы. Для них используется единое растяжение яркости на всём файле, сохраняющее цвет при перемещении. NoData и альфа-канал учитываются. Путь к файлу сохраняется в проекте, сам внешний снимок нужно переносить вместе с проектом. При открытии на другом компьютере его можно выбрать заново.

Выбор источника и видимость подложки сохраняются в проекте. Изменение отображения сохраняет предпросмотр оцифровки.

Подложка выходит за края карты на 8% её ширины и высоты с каждой стороны. «Вписать» показывает карту вместе с этим запасом; при увеличении к нему можно перемещаться. Привязка и область оцифровки карты сохраняются. Для внешнего GeoTIFF запас виден там, где в самом снимке есть данные.

## Вкладка «Яндекс Карты»

Отдельная вкладка открывает обзорную карту через JavaScript API Яндекс Карт. Доступны **Схема**, **Спутник**, **Гибрид**, масштабирование и перемещение. **К листу** показывает географическую область открытого растра. Зелёная линия отмечает рамку растра, розовая — применённый KML с его вырезами; флажок **Рамка и KML** скрывает эти отметки. Поверх схемы, спутника или гибрида отображаются исходная карта и применённые полигоны. Флажки **Исходная карта** и **Полигоны** независимо скрывают слои, ползунки меняют непрозрачность растра и заливки. Растр перепроецируется в эллипсоидальный Меркатор Яндекса (EPSG:3395), учитывает поворот, NoData и обрезку KML с отверстиями. Рабочее изображение используется в том же разрешении, что в редакторе. Локальные тайлы повторно используются из ограниченного кэша. После применения правки, отмены или загрузки проекта полигоны обновляются автоматически, сохраняя текущий масштаб и положение. Непринятый предпросмотр автообработки не показывается. Оцифровка и правки выполняются в первой вкладке.

Указанный стандартный ключ уже встроен. **Проект → Настройки карт** позволяет сохранить свой ключ JavaScript API или вернуть стандартный. Он хранится отдельно от ключа Tiles API основного редактора. Ключи не входят в проект. Выбор режима сохраняется при переходе между вкладками, страница при этом не перезагружается. Скрытая вкладка переводится в состояние с низкой активностью. Браузер использует собственный HTTP-кэш до 64 МБ; кэш тайлов редактора работает отдельно.

Вкладка создаётся при первом открытии, браузер не запускается при обычной оцифровке. Компоненты Qt WebEngine входят в зависимости; стартовые скрипты проверяют их наличие. Здесь используется JavaScript API 2.1, поскольку он поддерживает спутник и гибрид. Мобильный MapKit SDK не подключается к настольной версии. Проверены реальные загрузки схемы, спутника и гибрида на macOS.

## Цвета и форматы исходных карт

Поддерживаются RGB/RGBA GeoTIFF, TIFF с цветовой таблицей и RGB 0–255, записанный в uint16 с отдельным NoData. Палитра разворачивается до уменьшения изображения, чтобы номера цветов не смешивались в посторонние оттенки. Реальные 16-битные измерения требуют отдельного преобразования в цветную карту.

При большом числе устойчивых заливок подготовка автоматически расширяет поиск с 12 до 24 групп; для компактной палитры сохраняется прежний маршрут. Дополнительные параметры не нужны. Цветовая группа остаётся предложением, а не установленным геологическим подразделением. Проверки на трёх внешних картах и ограничения описаны в [VALIDATION.md](VALIDATION.md).

## Зернистые сканы

Подготовка автоматически оценивает цветную зернистость на светлых однородных участках — по листу и по отдельным окнам. Поэтому чистая большая часть листа не скрывает заметную шумную область. Усиленная обработка по локальным данным включается только при подтверждении несколькими окнами на существенной площади; одиночное повреждение, надпись и прозрачный край не должны определять режим всего листа. При выраженном шуме отдельно восстанавливает заливку под толстыми печатными штрихами и подавляет цветовую рябь, не изменяя исходное изображение. Сплошные тёмные и насыщенные узкие заливки получают отдельные цветовые опоры. На обычных сканах сохраняется прежняя обработка. Дополнительные переключатели не нужны; в окне подготовки появляется подпись **«восстановлены заливки зернистого скана»**.

Для признаков контактов и печатной текстуры остаётся исходный растр. Сложные подписи и тонкие близкие оттенки по-прежнему требуют проверки: очистка шума сама по себе не подтверждает геологическую точность. После обновления заново подготовьте TIFF, чтобы пересчитать уже открытый предпросмотр. Принятые ручные правки сохраняются при пересчёте.

## Обрезка по KML и слои

В разделе **Слои** нажмите **Обрезать по KML**. Выберите один контур или все контуры файла. Предпросмотр показывает, какая часть карты останется. **Обрезать** удаляет из рабочего изображения всё снаружи контура и внутри вырезов: там остаётся прозрачность, сквозь которую видна подложка. Готовые полигоны обрезаются по точной векторной границе. Последующая автообработка работает только внутри оставшегося участка. Поддерживаются отверстия, несколько полигонов и преобразование координат из WGS84 в систему GeoTIFF. При разделении объекта на части атрибуты сохраняются, дополнительные части получают новые номера.

Ctrl+Z или Cmd+Z отменяет обрезку карты вместе с обрезкой полигонов. **Вернуть** восстанавливает растр целиком, сохраняя текущие полигоны; для восстановления полигонов используйте отмену. Область и данные для восстановления изображения хранятся в проекте вместе с исходной маской NoData. Исходный TIFF не перезаписывается. После смены области выполните подготовку карты заново. Флажок границы скрывает только линию KML, обрезка остаётся действующей.

Флажки управляют исходной картой, полигонами и границей области. Для карты и полигонов доступны отдельные ползунки непрозрачности. Настройки сохраняются в проекте и копии восстановления. Изменение отображения сохраняет предпросмотр автооцифровки.

## Правка границы мышью

Откройте **Правка** и перетащите подсвеченную границу левой кнопкой. Захват работает в пределах 8 экранных пикселей. Приближайте карту, чтобы перемещать более короткую часть контура. Линия плавно изгибается между неподвижными концами участка и останавливается у стыков. Для точечного изменения включите **Только одна точка**. На длинном прямом ребре точка появится под указателем, если рядом нет подходящей вершины. Общая граница меняется у обеих сторон. После отпускания кнопки редактор проверяет геометрию и применяет допустимую правку. Ctrl+Z или Cmd+Z отменяет весь жест.

## Работа с близкими оттенками и спорными границами

Цвет под печатными штрихами дополнительно восстанавливается по видимой заливке с противоположных сторон в нескольких направлениях. Уверенное согласие помогает убрать промежуточные оттенки у текста. При конкурирующих цветах остаётся исходный расчёт. Палитра, внутренние оттенки и признаки границ рассчитываются отдельно от этой коррекции. Настраивать новый режим не требуется.

При восстановлении заливки под подписью алгоритм проверяет и отдельную пару фрагментов, включая небольшую помеху у крупной области. Объединение требует согласия цвета и печатной текстуры, а также связной видимой заливки на исходном скане. Проверяются тёмные и цветные штрихи контакта. Подтверждённый контакт сохраняется, в том числе когда его можно обойти через соседний фрагмент. Дополнительные настройки не нужны.

Если внутри одной цветовой группы есть несколько близких заливок с выраженными контактами, алгоритм повторно проверяет части после первого разделения. Каждая следующая граница должна подтверждаться цветом, связными областями и протяжённым тёмным штрихом. Это работает автоматически, дополнительных настроек нет. Изменение одной яркости, светлая сетка и короткая отметка не считаются достаточным основанием для разделения.

В «Подготовке карты» колёсико приближает участок под указателем. Кнопки «+» и «−» меняют масштаб по центру. Перетаскивайте увеличенную карту мышью, в том числе при включённой пипетке. Кнопка «Вся карта» возвращает общий вид. Чтобы отделить заливку, нажмите **Новая группа · пипетка** и щёлкните по однородной части нужной заливки. Программа ищет похожие пиксели внутри исходной группы. Подсветка показывает будущую группу до построения полигонов. Можно взять ещё один образец или сбросить палитру. Образцы действуют в текущей подготовке карты. Созданные полигоны и поля сохраняются в проекте.

В режиме «Цвет + границы» рядом с этапом расчёта появляется приблизительное оставшееся время. После построения откройте **Проверка · N** и перейдите к участку стрелкой. Кнопки **Назад** и **Вперёд** возвращают к участкам вместе с сохранённым решением. Малиновая отметка показывает место, вызвавшее сомнение при авторасчёте. Снимите **Подсветка сомнения**, чтобы рассмотреть оригинал в том же масштабе. Можно подтвердить участок или перейти к исправлению. Программа может предложить проверить объединение мелких фрагментов, положение общей границы или возможный пропущенный контакт внутри полигона. Перед правкой предпросмотр применяется явной командой.

Кнопка **Сохранить журнал** выгружает CSV с координатами участка на рабочем растре, причиной показа, решением и временем от перехода к участку до действия. В это время входят паузы. Сохраните журнал до открытия другого проекта или выхода.

## Автооцифровка геологического листа

При открытии GeoTIFF программа подбирает палитру и показывает **Подготовку карты**. Нажмите **Создать полигоны**, чтобы получить предпросмотр со всеми найденными заливками. Нажатие на цвет показывает соответствующие участки на карте. Можно исключить ненужную заливку, объединить оттенки в один класс или вернуться к автоматическому выбору. Кнопка **К карте** закрывает подготовку. Повторно открыть её можно кнопкой **Палитра**.

Метод **Цвет + границы** учитывает изменения цвета по обе стороны контакта, направление тёмных штрихов и плотность печатной текстуры. Области сначала выделяются на рабочем изображении. Если доступен более подробный исходник, алгоритм уточняет общий контакт соседей в узкой полосе по обе стороны границы. При этом дополнительно сравнивает цвет открытой бумаги с цветовыми опорами внутри соседних областей. Опоры строятся по подробному исходнику без тёмных штрихов и участков контура; мелкие участки без устойчивой опоры и посторонние цвета не получают такого дополнительного голоса. Перемещение сохраняет связность, отверстия и узкие перемычки. Мелкие округлые пятна с неуверенным цветом и слабым контуром могут присоединиться к соседу. После согласования штриховки и контактов выполняется повторная проверка оставшихся фрагментов: сохраняются уверенные редкие заливки, длинные узкие линзы, подтверждённые границы и участки на краю маски. При ручном исключении или объединении заливок такая очистка ограничена одним выбранным классом. Несколько отдельных полигонов могут иметь один цветовой класс. Геологические индексы задаёт пользователь. Расчёт выполняется на CPU и допускает остановку. Перед применением можно проверить результат на исходной карте.

Если одна заливка разделилась на фрагменты, алгоритм ищет внутри неё устойчивое повторение параллельных штрихов. Соседние участки с похожим направлением и шагом могут образовать общий полигон. В узких продолжениях программа ищет штрихи с тем же шагом и направлением между печатными краями полосы и уточняет контур по примыкающим вытянутым участкам заливки. При автоматическом выборе цветов краткий переход через близкий оттенок может соединить две части рисунка. Длинный тёмный контакт, пересекающий штриховку, учитывается при разделении областей. Алгоритм работает автоматически и сохраняет выбор целевых цветов.

## Повторная оцифровка и режим «Скан» · локальная разработка

В меню **⋯ → Параметры оцифровки** включите **Другие методы** и выберите **Обычный** или **Скан: подавление печати**, число групп
и порог мелких пятен. Нажмите **Рассчитать предпросмотр**. Прежние полигоны остаются
в проекте; флажок **Показать новый результат** переключает сравнение. **Применить**
принимает новое выделение, **Закрыть** удаляет только предпросмотр. Применение отменяется
одним шагом, в том числе при первом выделении карты. Карта в предпросмотре не выбирает
старые объекты под новыми контурами; для выбора снимите флажок или закройте предпросмотр.

Защищены принятые и изменённые объекты, а также объекты с геологическим индексом,
названием, примечанием или пользовательским значением, отличным от значения по умолчанию.
Их геометрия, ID, группы и атрибуты сохраняются точно. Автоматически назначенные defaults
сами по себе не защищают всю карту; ручное применение атрибутов помечает объект изменённым.
Новые полигоны занимают оставшуюся область, получают новые ID и defaults текущей схемы.
Обрезка выполняется по векторным границам, включая ручные перемещения между пикселями.
Возле сохранённых сложных контуров могут появиться мелкие фрагменты — они не удаляются
ценой потери покрытия. Предпросмотр сообщает количество сохранённых и новых объектов.

Режим «Скан» подавляет локальные тёмные печатные помехи и уменьшает влияние яркости бумаги.
Он экспериментальный: на одной предоставленной карте среднее IoU по 67 оставшимся объектам
выросло с 0,455 до 0,553, но 22 объекта стали хуже. Узкие тёмные области нужно проверять.
Протокол сравнения прежних режимов приведён в [AUTO_EVALUATION.md](AUTO_EVALUATION.md).

Предпросмотр не входит в сохранение, восстановление или экспорт до применения.
Изменение данных сбрасывает его, чтобы устаревший результат не затёр новые правки.
Для доступа к слоям и непрозрачности прокрутите левую панель; полоса прокрутки видна постоянно.

## Таблица и массовое заполнение · локальная разработка

Нажмите **Таблица** над картой. Таблица показывает основные и пользовательские поля;
для дополнительных столбцов прокрутите вправо. Двойной щелчок по ячейке закрывает таблицу,
выбирает полигон на карте и приближает его. Заголовок сортирует столбец; числа сортируются
по величине, незаданные значения остаются в конце.

Поиск работает без учёта регистра по номеру и всем значениям атрибутов. Доступны фильтр
состояния проверки и **Не заполнено обязательное**. При смене фильтра отметки сбрасываются;
сортировка сохраняет их. **Отметить найденные** выбирает все результаты фильтра, включая
строки за пределами экрана. По отдельности объекты отмечаются флажками слева.

Для массового заполнения выберите поле и значение внизу. По умолчанию включён режим
**Только пустые**: он пропускает заполненные значения, включая 0 и «Нет».
Кнопка **Подготовить** показывает поле, новое значение и точное количество изменений.
До подтверждения данные остаются прежними. Пустое значение очищает поле, если отключить
режим «Только пустые». Служебные ID, группу, происхождение и состояние проверки этим инструментом
менять нельзя. Изменённые объекты получают состояние «Изменён вручную» и защиту от автообработки.

Одно массовое заполнение отменяется одним действием. Изменения входят в обычное сохранение
проекта и GeoPackage. Если данные изменились после подготовки, устаревшее подтверждение
отклоняется. Таблица использует переиспользуемые видимые ячейки, а не создаёт элементы для всей карты.
Фильтры, отметки строк и ещё не применённое массовое значение не сохраняются в проекте.
Прямого редактирования отдельной ячейки внутри таблицы пока нет — для него откройте объект на карте.

## Настраиваемые атрибуты · локальная разработка

Справа нажмите **Поля… → Добавить поле**. В списке выберите предложенный атрибут или «Своё поле». Можно настроить до 64 дополнительных полей следующих типов —
текст, целое число, дробное число, «Да/Нет», дата и список вариантов. В новом проекте предусмотрены номер полигона, группа, примечание, состояние проверки и происхождение. Геологический индекс, возраст, литология и другие предметные поля добавляются по выбору. Код для ГИС задаётся латинскими строчными буквами, цифрами и `_`;
название для интерфейса можно писать по-русски. Код существующего поля не меняется.

Полю можно задать значение по умолчанию и обязательность. При добавлении поля значение
по умолчанию заполняет его у существующих объектов; после изменения самого значения по
умолчанию уже записанные значения остаются прежними. Новые полигоны получают текущие defaults.
Смена типа проверяет преобразование всех значений до применения; несовместимое изменение
отклоняется целиком. Удаление поля требует подтверждения и удаляет его значения у всех объектов;
действие можно отменить через Ctrl/Cmd+Z.

Выберите полигон, заполните поля и нажмите **Применить атрибуты**. Дробные числа можно вводить
с запятой. Даты: `ГГГГ-ММ-ДД`; «Не задано» отличается от нуля и от «Нет».
Обязательные поля разрешается оставить пустыми в рабочем проекте; перед экспортом GeoPackage
программа укажет первый полигон с незаполненным обязательным полем.

Структура и значения входят в `.geotrace`, включая автоматическую копию восстановления.
Пользовательские значения наследуются при разделении и ручной правке; объединение сохраняет
значения первого полигона. Повторная автообработка сохраняет структуру полей и защищённые объекты;
новые объекты получают значения по умолчанию.
В GeoPackage числа и даты имеют соответствующие типы; «Да/Нет» экспортируется как 1/0,
списки — как строки. Названия полей в ГИС соответствуют кодам. Справочник вариантов,
обязательность и defaults хранятся в проекте, не становятся ограничениями базы GeoPackage.

Текущий формат проекта имеет версию 3. При открытии версий 1 и 2 заполненные геологические индексы и названия становятся редактируемыми полями проекта. Перенос схемы между проектами отдельным шаблоном пока не реализован.

## Рисование с нуля и вершины · локальная разработка

- **Создать полигон:** щелчками отметьте минимум три вершины, нажмите
  «Предпросмотр», затем «Применить правку». Контур замыкается автоматически.
  Автоматическая сегментация не нужна — можно начать сразу после открытия TIFF.
  Новый объект сразу выбирается для заполнения атрибутов справа.
- **Выбрать полигоны:** выберите один объект, затем переключитесь на
  **Переместить вершину**. Перетащите круглый маркер. После отпускания мыши
  появится предпросмотр; примените правку или нажмите «Сбросить перемещение».
  Простое нажатие без перемещения не меняет вершину. Для плотных контуров увеличьте масштаб.
- Общая вершина обновляется у всех примыкающих объектов, включая узел трёх областей
  и общую границу отверстия с островным полигоном. Сохраняются ID и атрибуты каждого объекта.
  Соседское ребро при необходимости получает промежуточную вершину.
- Внешняя граница объекта может менять охват в свободной части карты; внутренняя общая
  граница сохраняет покрытие. Пересечения, наложения, выход в NoData и самопересечения отклоняются.
- После принятия вершины объект остаётся выбранным для продолжения правки. Принятые
  изменения сохраняются в проекте/GeoPackage и отменяются обычной командой отмены.

Новый контур добавляется только на свободное место. Если карта уже полностью покрыта
полигонами, используйте разделение или изменение границ. Автоматической привязки новых
точек к существующим рёбрам и добавления/удаления отдельных вершин пока нет.
Нарисованный, но ещё не применённый контур и предпросмотр не входят в сохранение проекта.

## Ручная правка полигонов · локальная разработка

Выберите инструмент **Выбрать полигоны**. В этом режиме добавляйте любое количество объектов щелчками. Первый выделяется синим, остальные оранжевым; повторный щелчок снимает выбор. Выберите инструмент **Лассо** и обведите участок зажатой левой кнопкой. Захватываются полигоны, хотя бы частично попавшие внутрь; одно касание границы не считается. Ctrl/Cmd или Shift добавляет область к текущему выбору. Короткий щелчок в режиме лассо также переключает один объект. Средняя кнопка перемещает карту, колесо меняет масштаб.

- **Объединение:** выберите соседей щелчками или лассо → **Объединить выбранные**. Правка применяется сразу; Ctrl/Cmd+Z отменяет всё объединение одним действием. Каждая связная группа объединяется отдельно, одиночные и невыбранные объекты сохраняются. В каждой группе остаются ID, группа и атрибуты первого выбранного объекта. При выделении лассо порядок определяется номерами объектов. Отверстия и общая площадь сохраняются. Дополнительно доступен **Предпросмотр объединения**, если нужно сначала проверить результат.
- **Разделение:** выберите один объект → «Разделить линией» → щелчками задайте линию →
  «Предпросмотр» → «Применить правку». Обе части наследуют атрибуты; большая сохраняет ID,
  вторая получает новый. Затем задайте атрибуты каждой части отдельно.
- **Общая граница:** выберите двух соседей → «Общая граница» → проведите новую разделяющую
  линию → предпросмотр и применение. Внешний контур пары сохраняется. ID и атрибуты относятся
  к сторонам с наибольшим суммарным пересечением с прежними областями; при неоднозначности операция отклоняется.

Линию начинайте и заканчивайте у внешнего контура выбранного объекта/пары или за ним.
Концы в пределах 5 рабочих пикселей от внешнего контура продлеваются на 12 пикселей по направлению
крайних сегментов. Линия должна разделять область ровно на две части без самопересечений.
Части меньше 0,25 рабочего пикселя по площади отклоняются. В местах сложных разветвлений
может потребоваться более короткая правка или несколько последовательных операций.

Предпросмотр показывает новые контуры; исходные данные изменяются только после применения.
Операции отменяются Ctrl/Cmd+Z и сохраняются в проекте/GeoPackage. Отредактированные объекты
защищены от автоматической перезаписи, включая пересечения внутри пикселя.
Линия и предпросмотр — временные: перед сохранением проекта примените правку.
Геометрическая корректность не означает правильность геологической интерпретации.

## Текущая локальная разработка: проекты

- **Сохранить проект** / Ctrl или Cmd+S: карта, полигоны, применённые атрибуты и точки подсказок в `.geotrace`.
- **Сохранить как…** / Ctrl или Cmd+Shift+S: отдельная копия проекта.
- **Открыть…** принимает GeoTIFF и проекты. Проект содержит рабочую копию растра, поэтому
  открывается даже после перемещения исходного TIFF. Полноразмерный TIFF не включается:
  рабочее разрешение по-прежнему ограничено 1600 пикселями по длинной стороне.
- Автоматическая копия создаётся при изменениях, проверка каждые 5 секунд в свободное время.
  После сбоя следующий запуск предлагает восстановление. Последние изменения после завершённого
  автосохранения могут не попасть в копию; во время вычислений и выбора файлов автосохранение ждёт.
- Атомарная запись защищает предыдущий файл от незавершённого сохранения.
- Экспорт `.gpkg` отделён от сохранения проекта и не снимает индикатор несохранённых изменений.

История отмены и предварительная маска выделения между запусками пока не сохраняются.
Точки подсказок восстанавливаются; нажмите «Уточнить область» для пересчёта маски.
Текст в полях атрибутов нужно применить перед сохранением. Копии восстановления лежат в
системной папке данных приложения GeoTrace, а не рядом с исходной картой. Сохранение проекта
или явное закрытие без сохранения удаляет текущую копию восстановления.

Эти изменения разрабатываются локально. Публикации и полные прогоны выполняются по завершении
существенных этапов; в процессе проверяются только затронутые сценарии.

## Как попробовать

1. Откройте привязанный RGB/RGBA GeoTIFF, 8 бит на канал.
2. Откройте **⋯ → Уточнить область…**. Выберите размер рамки до первой точки.
3. В режиме **Включить (+)** щёлкните внутри нужной геологической области.
4. В режиме **Исключить (−)** отметьте соседнюю область, которую брать не нужно.
5. Нажмите **Уточнить область**. Оранжевое выделение пока является только предложением.
6. При ошибке добавьте точки, смените метод или допуск цвета и повторите уточнение.
7. Нажмите **Принять область**. Затем переключитесь на **Выбрать полигон**, заполните
   атрибуты и нажмите **Применить атрибуты**.
8. Нажмите **Сохранить проект**. Для работы в другой ГИС отдельно используйте **Экспорт .gpkg**.

Если выделение достигает рамки, программа предупреждает о возможном обрезании объекта.
Можно принять фрагмент явно либо сбросить точки и увеличить рамку. Принятые области защищены:
для ручного изменения используйте инструменты слева; принятие также можно отменить, если оно ещё в истории.
`accepted` означает принятие геометрии пользователем, а не автоматическое подтверждение геологии.

Колесо меняет масштаб; перетаскивание перемещает карту; «Вписать» возвращает общий вид.
В дополнительных параметрах оцифровки доступны три режима с предпросмотром и сохранением защищённых объектов.
Локальные подсказки предназначены для работы с отдельными участками.

## Что пока не решено

Геологические названия и индексы требуют интерпретации по легенде.
На светлых заливках, штриховке, узких полосах и подписях результат может быть неудовлетворительным.
Сравнение на четырёх фрагментах описано в `EVALUATION.md`; это не заявленная точность продукта.

Рабочее изображение в проекте имеет до 1600 пикселей по длинной стороне. Для нового режима палитра определяется по этому изображению, а исходный TIFF даёт дополнительные сведения о печатных линиях. Подробный анализ ограничен 12 млн пикселей. При отсутствии исходника режим использует встроенный растр. Окно подготовки показывает фактическое разрешение.
Алгоритм подавления печати может ошибочно удалить настоящие тонкие тёмные объекты.

Ещё отсутствуют: добавление/удаление отдельных вершин и привязка новых контуров к соседям,
шаблоны схем атрибутов, повторное открытие GeoPackage в приложении,
KML-обрезка и самостоятельные установщики.
Поля атрибутов попадают в результат только после кнопки «Применить атрибуты».

Экспорт создаёт новый файл, не заменяя существующий. Исходные карты не изменяются.
Произвольные наложения в одном полигональном слое не допускаются. Независимое сглаживание
полигонов отключено для сохранения общих границ. Площадь в физических единицах ещё не вычисляется.

## Установка из исходников

Нужен Python 3.11 и интернет для первого скачивания библиотек.

- macOS: `Start GeoTrace.command`.
- Windows: `Start GeoTrace.bat`.

Это сценарии запуска из исходников, а не установщики. При сбое начальной установки удалите
только созданную рядом папку `.venv` и повторите запуск.

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -e ".[dev]"
.venv/bin/python -m geotrace.app
```

В Windows вместо `.venv/bin/python` используйте `.venv\Scripts\python.exe`.

### Необязательный MobileSAM

Обычная установка не включает PyTorch и модель. На текущем Mac исследовательское окружение
уже настроено; общий сценарий `Открыть GeoTrace.command` рядом с папкой проекта подключает его.
На другой машине установите исследовательские зависимости и официальный MobileSAM:

```sh
python -m pip install -e ".[research]"
python -m pip install "git+https://github.com/ChaoningZhang/MobileSAM.git@f706ad9c4eb7f219c00d9050e46328518ffb65d2"
python -m geotrace.app --sam-checkpoint /absolute/path/to/mobile_sam.pt
```

Для команды установки из Git нужен Git. Веса `weights/mobile_sam.pt` берутся из
[официального репозитория MobileSAM](https://github.com/ChaoningZhang/MobileSAM).
Приложение не скачивает их автоматически и не передаёт карты на сервер.
Исследовательские зависимости и веса не входят в основной дистрибутив GeoTrace.
В этом прототипе нейросеть работает на CPU; GPU/CUDA-ускорение пока не реализовано.
