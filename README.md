# GeoTrace · 0.8 beta 1

Настольная оцифровка геопривязанных геологических карт: автоматическое построение полигонов, проверка спорных мест и ручная правка общих границ. Основная платформа — Windows, также поддерживается macOS.

Это бета-версия. Цветовые группы не заменяют геологическую интерпретацию по легенде. Средний IoU 0,90 пока не достигнут; результаты текущего выпуска приведены в [отчёте о качестве](docs/QUALITY.md).

## Скачать и запустить

Скачайте архив **GeoTrace-0.8.0-beta.1-buildN.zip** из [релиза 0.8 beta](https://github.com/TheJakSin/GeoTrace/releases/tag/v0.8.0-beta.1), распакуйте в отдельную папку и откройте:

- Windows: `Start GeoTrace.bat`. Требуется установленный Python 3.11 с Python Launcher.
- macOS: `Start GeoTrace.command`. Требуется Python 3.11; при запрете запуска используйте Terminal, как описано в [руководстве](docs/USER_GUIDE.md).

При первом запуске нужен интернет для установки библиотек. Архив и wheel пока не являются самостоятельными установщиками. Видеокарта NVIDIA для основной оцифровки не требуется: расчёт выполняется на процессоре. Большие исходники анализируются с ограничением разрешения и памяти.

## Первый результат

1. Откройте GeoTIFF с геопривязкой.
2. В подготовке проверьте найденные цвета. При необходимости отделите заливку через **Новую группу · пипетка**.
3. Нажмите **Создать полигоны**, дождитесь предпросмотра и сравните с исходником по Shift.
4. Проверьте сомнительные участки, примените результат и исправьте границы инструментами слева.
5. Сохраните `.geotrace`. Для другой ГИС отдельно экспортируйте `.gpkg`.

Исходный TIFF не перезаписывается. Сохраняются применённые изменения; незавершённый контур и непринятый предпросмотр в проект не входят.

## Возможности

- Метод «Цвет + границы»: восстановление заливок под печатью, совместный учёт цвета, штриховки, линий и топологии; уточнение контактов по подробному исходнику.
- Палитровые, RGB/RGBA GeoTIFF и RGB 0–255, записанный в uint16; NoData и маски. Произвольные многоспектральные и радиометрические данные не являются входом оцифровки.
- Общая граница перетаскиванием, точечная правка, лассо и объединение, разделение, новые полигоны.
- Настраиваемые атрибуты, фильтр по группе, таблица и массовое заполнение.
- Реальная обрезка рабочего растра и полигонов по KML, переносимые проекты, восстановление и отмена.
- Кэшируемые подложки, отдельная вкладка Яндекс Карт с растром и полигонами, справка F1 и горячие клавиши.

## Разработка

Нужен Python 3.11. В Windows путь к Python окружения — `.venv\Scripts\python.exe`.

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -e ".[dev]"
.venv/bin/python -m geotrace.app
.venv/bin/python -m pytest -q
.venv/bin/python -m build
```

[Checks](https://github.com/TheJakSin/GeoTrace/actions/workflows/checks.yml) проверяет Windows и macOS и собирает пакеты. Карты пользователя, эталоны, проекты, API-ответы и веса моделей в Git не включаются. Установка дополнительных исследовательских методов описана в [руководстве](docs/USER_GUIDE.md#дополнительные-методы).
