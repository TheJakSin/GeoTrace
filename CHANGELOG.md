# Изменения

## 0.8 beta 1 · 21 ноября 2026

- Немного точнее положение общих контактов: усилен ограниченный голос цвета открытой бумаги в подробном анализе, с сохранением защиты печати и топологии. Прирост подтверждён на трёх размеченных наборах; IoU 0,90 пока не достигнут. Проверены семь вариантов карт пользователя и три внешних карты.
- Версия и build видны в заголовке приложения и справке F1. Номер build взят из Checks, метаданные пакета связаны с проверенным коммитом. Публикация тега больше не создаёт дублирующую push-сборку.
- Переписано руководство, добавлены описание алгоритма, отчёт о качестве и порядок выпуска. Полное руководство доступно из F1.
- Добавлен `tools/benchmark_quality.py` для воспроизводимого запуска текущего метода и оценки по независимому эталону.
- Вывод инструмента оценки совместим с перенаправленной консолью Windows в однобайтной кодировке; сохранённый отчёт остаётся UTF-8. Проверка интерфейса атрибутов теперь проверяет доставку нажатия перед проверкой результата.

Документация и точные замеры: [docs/QUALITY.md](docs/QUALITY.md).

## 0.3.0 alpha 1 · 21 ноября 2026

### Автоматическая оцифровка

- Совместная оценка заливки, печатных линий, внутренних оттенков и штриховки; уточнение общей границы по подробному исходнику с ограничением памяти.
- Восстановление заливок зернистого скана и проверка компактных печатных фрагментов.
- Автоматический поиск до 24 устойчивых цветовых групп при заполнении прежнего лимита; ручные новые группы, пипетка, перемещение карты и исключение заливок в подготовке.
- Дополнительное согласование областей по цвету открытой бумаги, локальным пробам и текстуре. Тёмная непрерывная линия, отличие бумаги, штриховка и недостаток проб запрещают такое объединение. Ручные группировки не затрагиваются.
- Чтение палитровых GeoTIFF и RGB 0–255 в uint16 с NoData. Цвета разворачиваются до уменьшения изображения.
- Предпросмотр, отмена обработки, сохранение ручных объектов при повторном запуске, оценка оставшегося времени и переход между сомнительными участками.

### Редактор и проекты

- Переносимые проекты `.geotrace`, атомарное сохранение и восстановление.
- Перетягивание общей границы, объединение нескольких выбранных полигонов, лассо, разделение, создание полигонов и правка общих вершин.
- Конструктор атрибутов, фильтры таблицы и массовое заполнение выбранной группы.
- Настраиваемая обрезка по KML с фактическим удалением области за контуром.

### Карты и интерфейс

- Компактная светлая рабочая область, режим просмотра без случайного выделения, слои поверх карты и сохранение положения при открытии панелей.
- Горячие клавиши, краткие подсказки, сравнение по Shift и справка F1.
- Кэшируемые подложки редактора и отдельная вкладка Яндекс Карт через JavaScript API: исходный растр и полигоны поверх схемы, спутника или гибрида.

### Проверки и ограничения

Подробные замеры, источники внешних карт и ограничения — в `VALIDATION.md`. Автоматические цветовые группы не являются установленными геологическими подразделениями. Цель среднего IoU 0,90 по полигонам не достигнута; результат требует проверки, особенно у близких заливок, тонких контактов и печатных помех.

Выпуск содержит исходный проект с командами запуска для Windows и macOS и Python-пакеты. Это предварительная версия, не самостоятельный установщик; для первого запуска нужны Python 3.11 и интернет для зависимостей. Исходные карты пользователя и исследовательские массивы в выпуск не включены.
