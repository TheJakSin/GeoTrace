# GeoTrace 1.1.0

Локальная версия 1.1.0 посвящена группам полигонов, редактированию геометрии и отображению стыков сканов. Публикация на GitHub и сборка установщиков отложены по запросу пользователя. Новый номер build пока не присваивался.

- Группы проекта можно создавать, переименовывать, перекрашивать, скрывать и удалять с переносом объектов. Группа выбранных полигонов меняется в атрибутах. Все эти изменения отменяются.
- После сопоставления листов обработанные образцы исчезают из выбора, а лишние классы удаляются. Геометрия и пользовательские атрибуты сохраняются. Автоматическая сшивка временно отключена, её кнопка убрана.
- Новый полигон можно нарисовать внутри существующего или поверх нескольких соседей: область вырезается из них с общей границей. Оставшиеся части сохраняют атрибуты, новый объект получает значения по умолчанию.
- Исправлены численно вырожденные внутренние щели после объединения и покрытые ими автоматические микрофрагменты. Реальные отверстия сохраняются. При открытии проекта используется сохранённый результат без непрошеной пересборки.
- Контуры в редакторе рисуются векторно с постоянной экранной толщиной. Ползунок правки 0,5–4 px помогает работать на большом увеличении и не меняет геометрию или стиль экспорта.
- Добавлено отключаемое сглаживание обнаруженной светлой краевой полосы на точно соприкасающихся сканах: не более двух исходных пикселей по обе стороны стыка. Реальные зазоры и внешние края не заполняются. У сопоставленных полигонов одной группы скрывается только техническая обводка общего края листов; геометрия не объединяется.
- Обновлены руководство пользователя и описание возможностей, в том числе офлайн-справка готового приложения.

Добавлены автоматическое бережное сглаживание и ручной инструмент с предпросмотром; кеш подробной карты; оформление конкретной группы нажатием на цвет; обновлённое меню проекта; проверка и скачивание обновлений. Первый новый знак «Изолиния G» используется в приложении, заставке и установщиках. Руководство и обзор содержат поясняющие иллюстрации.

Выпуск содержит установщик Windows x64, пакеты Mac Apple Silicon и Mac Intel, архивы приложений и пользовательскую документацию DOCX/PDF. Windows устанавливается в Program Files с запросом администратора. Обновление сохраняет проекты и настройки; прежняя пользовательская установка Windows переносится. Пакеты не имеют платного сертификата издателя и нотариализации Apple. Номер build соответствует успешному Checks, указанному ниже. Публикация допускается только после проверки всех трёх платформ и установленного приложения.

Прочитайте [руководство](USER_GUIDE.md), [описание возможностей](PRESENTATION.md) и [проверки 1.1](QUALITY_1_1.md). Автоматическое распознавание требует проверки специалистом; цель среднего IoU 0,90 не достигнута. Исправления редактора не означают нового измерения точности распознавания.
