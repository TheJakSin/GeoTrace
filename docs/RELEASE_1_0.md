GeoTrace 1.0.0 добавляет проект участка с несколькими полными листами, общими классами, отдельными линейными объектами и выпуском оформленных карт.

- Окно EPSG:3857, геодезические площади и длины, сводка по участку.
- Раздельная подготовка листов, пипетка новых групп, рамка без легенды, сохранение настроек, общий предпросмотр и защита ручных правок.
- Соответствия групп разных цветов, приоритет перекрытия, сшивка классов, проверка стыков. Сопоставление A/B непосредственно на карте и отдельная команда сшивки.
- Ручные разломы, типы и цвета с пипеткой, боковые атрибуты, продолжение, вершины, разделение и соединение. Автоматический поиск линий помечен «Бета».
- Оформление объектов, подписи, макет с четырьмя вкладками, чёрно-белая масштабная линейка, шаблоны, легенда, PDF/PNG/SVG и атлас KML.
- Переносимые проекты с исходниками, контрольные сохранения, поиск действий, быстрый запуск и офлайн-руководство.
- Исправлены контраст полей, отмена переноса вершины, статус автосохранения. Плавные жесты тачпада, большее отдаление, номер группы в атрибутах. Новый логотип приложения.
- Автономные установщики Windows x64 и macOS Apple Silicon/Intel. Python отдельно не нужен.

Минимум для данной Mac-сборки — macOS 14.4. Windows — 64-разрядная Windows 10/11. Платные сертификаты издателя и нотариализация не применялись; возможны системные предупреждения.

Автооцифровка требует проверки. 0 не заявляет такого результата. Данные Geology/Research в справке обозначают роли направлений и не означают автоматического определения геологических подразделений.

Номер build соответствует этому запуску Checks. В JSON самопроверки отдельно показаны запуск собранного приложения и экспорт данных; в `installed-*` — запуск из установленного пакета. Контрольные суммы находятся в `SHA256SUMS.txt`. Руководство и документ о возможностях приложены в DOCX/PDF.
