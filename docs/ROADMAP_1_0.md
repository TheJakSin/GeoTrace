# GeoTrace 1.0 — согласованный объём

Рабочее приложение сохраняет собственное имя и оформление GeoTrace. Проекция окна
EPSG:3857; измерения геодезические. Финальная версия после завершения этапа — 1.0.0,
номер сборки определяется успешным запуском Checks. Установщики собираются после
реализации функций, без промежуточного тестового установщика.

## Проект участка

- [x] Несколько полных геопривязанных листов и один активный участок KML.
- [x] Полная палитра и отдельная оцифровка каждого листа, независимо от KML.
- [x] Общие классы проекта и соответствия групп разных цветов на разных листах.
- [x] Предпросмотр и проверка сшивки, конфликтов перекрытия, щелей и дублей.
- [x] Повторный расчёт сохраняет ручную работу; история, контрольные сохранения.
- [x] Совместимость со старыми проектами и переносимая упаковка исходников.
- [x] Площадь, доля класса в участке, длина и сводка; пересчёт после изменения.

## Объекты и оформление

- [x] Отдельные полигональные и линейные слои, видимость и блокировка.
- [x] Несколько типов линий, образцы цвета, необязательная автоматическая трассировка.
- [x] Рисование, продолжение, перенос участка/вершины, разделение и соединение линий.
- [x] Отдельная схема атрибутов линий и вычисляемая длина.
- [x] Заливки, контуры, прозрачность, ширина/штрих линий, подписи по атрибуту.
- [x] Контекстные инструменты и компактные панели без изменения положения карты.
- [x] Проверка стыков и сомнительных участков; шторка удалена по замечаниям 25 ноября.

## Выпуск карты

- [x] Отдельное окно макета, шаблоны, область KML/вид/рамка.
- [x] Формат бумаги, масштаб, подписи, легенда, сетка, север, линейка, оформление.
- [x] PDF и PNG из данных, векторные контуры/текст; GeoPackage с отдельными слоями.
- [x] Сохранение макетов и атлас нескольких участков.

## Запуск и поставка

- [x] Быстрая заставка с собственной эмблемой GeoTrace и короткой анимацией.
- [x] Реальная загрузка одновременно с заставкой, с минимальным временем показа 1,1 секунды по замечаниям 25 ноября.
- [x] Маленькая подпись TJS TECH × TJS HORIZON только на заставке.
- [x] Начальный экран, последние проекты; прямое открытие файла без лишнего экрана.
- [x] Поиск действий Ctrl/Cmd+K; аккуратная версия, полные сведения в справке.
- [x] PRIME — ПО; MERIDIAN/DATA — ГИС; GEOPHYSICS — предметные задачи;
      XLAB/QUANTUM — исследования. Подробные роли в справке и установке.
- [ ] Автономные Windows/macOS приложения без установленного Python.
- [ ] Фирменные установщики после реализации; Mac-мастер без обязательного
      сертификата Developer ID, с учётом системных предупреждений, либо DMG.
- [x] Пользовательское руководство DOCX/PDF со скриншотами и учебным примером.
- [x] Презентационный документ DOCX/PDF: функции, применение, реальные замеры экономии времени.
- [x] Регрессия качества, измерений, сохранности ручных объектов и производительности.
- [ ] Проверенный GitHub-релиз, контрольные суммы и номер сборки.

Источник архитектуры брендов: предоставленный пользователем
`TJS_GROUP_Architecture_V3.pdf`, страницы 2, 4–7. Это описание брендовых ролей,
а не утверждение о юридических лицах или о наличии нейросетевого метода.
